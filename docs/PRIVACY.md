# 隐私说明

ServerPulse 服务器监控（Halo 插件）不收集、不存储、不上传访客或站点数据。

## 数据处理

- 插件在 Halo 服务端读取服务器指标（CPU、内存、磁盘、系统、进程、JVM）。
- 指标只在 Halo 进程内存中缓存，用于页面展示；历史曲线最多保留约 4 分钟的采样点，Halo 重启后清空。
- 插件不写入数据库，不创建持久化文件。
- 插件不向任何第三方服务发送数据，不包含遥测、统计、崩溃上报、广告或远程配置。
- 前端不加载外部 CDN、字体、图片或脚本。

## 访问控制

- 默认仅登录用户可查看监控数据。
- 站点管理员可以显式开启公开访问；开启后，任何访问 `/pulse` 的访客都能看到服务器概况。
- 监控 API 只提供只读 `metrics` 资源，不包含用户数据、站点内容、订单或凭据。

## 日志

插件只在启动、停止、指标采集失败等场景输出必要日志，不记录访客身份、IP 或完整指标数据。

## 联系方式

请通过项目仓库的 Issue 反馈隐私相关问题：https://github.com/litxiaoxi/halo-plugin-server-pulse/issues 。
